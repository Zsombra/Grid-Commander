# The MCP reference is a major version behind

## What

`docs/BATTLEGRID_MCP_REFERENCE.md` opens by naming the server it describes:
`battlegrid v17.2.0`, probed 2026-08-11. The platform is now **v18.2.0**, and
`docs/battlegrid-mcp-surface.json` and `docs/BATTLEGRID_SURFACE_MAP.md` were
refreshed 2026-08-12. The reference was not, because it cannot be produced
from what the refresh generates.

`tools/probe_mcp_surface.py` writes the surface record. `tools/generate_mcp_reference.py`
takes a **directory of raw JSON-RPC dumps** as `sys.argv[1]` — `init.txt`,
`tools.json`, `prompts.json`, `resources.json`, `restemplates.json` — captured
by some step that is not in the repository. So the two artifacts CLAUDE.md
describes as regenerated by one tool are in fact produced by two, and only one
of them is reachable from a probe.

## Why it matters

p3: the reference is documentation, and the machine-read artifact — the surface
record nine conformance guards compare against — *is* current. But CLAUDE.md
points a reader at the reference as the map of the surface, and it now
describes a superseded version while sitting next to a record that does not.

Deliberately **not** fixed by editing its header to say v18.2.0. That would
make the file claim a version its body does not describe — the same
looks-fresh-but-is-not failure the design lane spent today learning to avoid.

## Evidence

- `docs/BATTLEGRID_MCP_REFERENCE.md:4` — "server `battlegrid v17.2.0` … on
  2026-08-11".
- `tools/generate_mcp_reference.py:4` — `SP = sys.argv[1]`, then five
  `open(f"{SP}/…")` calls for files nothing in the repo writes.
- `docs/battlegrid-mcp-surface.json` — now `18.2.0`, probed 2026-08-12.

## First step

Find or write the capture step. A small script that opens one MCP session and
dumps `initialize`, `tools/list`, `prompts/list`, `resources/list` and
`resources/templates/list` into a directory would close the gap and make
CLAUDE.md's "regenerate both" sentence true. The probe already speaks the
protocol; it is the dump-to-disk that is missing.
